Event Management System

A web-based Event Management System developed as a college project.

Technologies Used

- HTML, CSS, JavaScript
- Node.js
- Database integration

Features

- Event management
- Event information and details
- Database connectivity

How to Run

1. Install Node.js.
2. Download or clone this repository.
3. Install the required dependencies using "npm install".
4. Configure the required environment variables.
5. Start the application using the appropriate command from "package.json".

Project Type

MCA College Project
